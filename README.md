# TRADE OS — Interactive Prototype v1.0

Dark UI demo for Trader and Admin, prepared for GitHub Pages.

## Publish
1. Create a GitHub repository named `trade-os`.
2. Upload `index.html`, `.nojekyll`, and this README to the repository root on branch `main`.
3. Go to **Settings → Pages → Build and deployment**.
4. Select **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**.
5. Visit `https://YOUR_USERNAME.github.io/trade-os/` after deployment completes.

## Important
This is a static demonstration with mock data. No broker execution, backend, real-time market data, user authentication, or database. Do not put credentials or real customer information in the repository.
